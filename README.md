# Pillcount

Track your daily pill intake with counts, timestamps, and streaks

**Live:** https://pillcount.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `pillcount`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
